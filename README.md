# Portal de Notícias 📰

Projeto desenvolvido como **primeira tarefa do módulo de HTML** do curso de front-end. O projeto consiste em um portal de notícias fictício com estrutura semântica básica, representando o ponto de partida da jornada no desenvolvimento web.

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3

## 💡 Contexto

Este é o primeiro projeto do portfólio — desenvolvido no início dos estudos de front-end. Comparado aos projetos mais recentes como Pingenti e Forge Cursos, serve como registro da evolução ao longo do curso.
